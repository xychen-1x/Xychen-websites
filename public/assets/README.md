# Visual asset system

This directory contains temporary, locally authored visual assets for the Xychen website. They are deliberately easy to replace without changing page structure.

## Planned asset locations

- `brand/`: wordmarks, marks, favicon source, and brand exports.
- `backgrounds/`: subtle textures and section backgrounds.
- `illustrations/`: original decorative illustrations.
- `banners/`: reusable section and campaign artwork.
- `content/`: article thumbnails and editorial images.
- `games/`: game-specific artwork and approved screenshots.
- `social/`: official platform marks, subject to their brand guidelines.
- `video/`: optimized video files and poster images.

## Replacement rules

1. Keep the public URL stable when replacing an asset, where practical.
2. Use descriptive lowercase filenames and hyphens.
3. Prefer SVG for original vector artwork and icons; use WebP/AVIF for photographic content, with a suitable fallback when needed.
4. Do not use invented gameplay screenshots, unverified game artwork, or platform logos drawn to imitate official marks.
5. Give meaningful images descriptive alternative text. Decorative artwork must use empty alt text.
6. Avoid shipping GIF/video unless it adds information or a clear experience benefit.
7. Export Open Graph artwork to a crawler-compatible raster format (PNG or JPEG) before publishing it in social metadata. The editable vector source can be kept here.

## Trial status

These assets establish a visual direction, not a final brand package. Replace or redesign them when approved real-world assets become available.
